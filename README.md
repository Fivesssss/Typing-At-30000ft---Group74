train your typing ability in a game like enviournment. Typing is a key skill to have in this day and age, 
but people tend to neglect training it.

 - GSON(JSON parser)
 - Junit Jupiter for unit testing

If you use the source code the gradle wrapper should handle all dependencies for you

RUNNING BUILT JAR FILE:

2. double click the jar file to launch game
3. if that doesnt work then go to terminal go to the location of the app.jar and run java -jar app.jar


RUNNING FROM SOURCE CODE:
- We assume you have already downloaded all the source code

1. First run ./gradlew clean
2. Then run ./gradlew build
3. The resulting jar file should be within rootFolder\app\build\libs
4. You can run this in 2 different ways
5. Starting this with the first method, Double clicking the jar file should launch the game
6. If that doesnt work or you want to try another way go to the terminal and go to the folder where app.jar is present
7. run the command java -jar app.jar
8. game should run now

TEACHER CONTROLS:

- To access the parental controls tab, you must:
1. Create a new account and set the account type to teacher
2. You will then be prompted to put in the teacher code, which is “plane123”
3. After you have created the account, log in with your newly created username and password
4. You will then be at the main menu screen, from there navigate to the settings tab
5. There will be 3 tabs at the top of your screen. Click the tab labeled “Teacher Controls”
6. From there, you can access all of the teacher controls and can reset passwords, typing stats, and the leaderboard

USER GUIDE:

1. When you enter the game you will be brought to the login/create account screen.
2. Can either login with the given demo account information or create a new account.
3. New accounts must have different usernames and be more than 3 characters in length and less than 
   15 characters in length, passwords just must be more than 3 characters in length.
4. If a teacher account is being created a pop-up will show with a teacher code needed, enter the 
   code given at the top of the README file to create the account.
5. After logging in you will be brought to the main menu where you can access the tutorial, credits, 
   and exit the game where your data will be automatically saved. You can also log into another account 
   with the change account option.
6. If you click play you will be brought to the game mode select screen where you can either choose 
   endless or level. Endless will bring you right to endless gameplay and level will bring you to the 
   level select screen where there are 5 levels which unlock by beating the previous (level one unlocked 
   automatically).
7. You can pause and go back to the main menu or restart anytime in any gameplay with the pause button 
   in the top right of the gameplay screen.
8. Level completion and game over screens give the ability to restart, continue to next level, and access
   the main menu.
9. Currency is received by playing the game which can be spent in the cosmetic and power-up shop which 
   alter what the game looks like and gives advantages to the user in game (see tutorial for in-depth 
   explanation).
10. The user can look at all the general binds in the settings menu. If the user has a teacher account 
    they will see teacher controls and typing statistics in settings where they can access all accounts 
    and reset their stats, reset their password, and reset the leaderboard.
11. You can exit the game from the main menu which will automatically save all your data.
